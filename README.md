# Ken Tattoo — Luxury React Website

A responsive editorial landing page for Ken Tattoo, Vientiane, Laos.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Included
- React + Vite
- Framer Motion reveal/entrance transitions with reduced-motion support
- Lucide icons
- Responsive mobile navigation
- Asymmetric tattoo inspiration gallery and keyboard/lightbox interactions
- Consultation form validation and mailto draft handoff (no backend required)
- Click-to-call and Google Maps directions
- SEO metadata, Open Graph metadata, favicon
- TCP IT Solution developer credit

## Before going live
1. Replace the Unsplash image URLs with studio-owned or properly licensed photographs. These are illustrative inspiration images, not confirmed examples of Ken Tattoo's own work.
2. Add the canonical URL once the final website domain is known.
3. If the studio wants form submissions delivered automatically, connect a backend or form service and update the consultation submit handler. Currently the form does not transmit or store data; it prepares an email draft after validation.
4. Confirm current opening hours directly with the studio. The site only displays the supplied closing time of 8:00 PM.
5. Add social profile links only after the studio's official accounts are verified.
